# Export page as image

The source build can export one current edited PDF page as PNG or JPEG. Open a PDF, choose **Export page as image** from Menu or All tools, select PNG or JPEG and 72, 150, or 300 DPI, then choose a new location in Windows. PNG is the initial format and 150 DPI is the initial resolution. Canceling the save picker creates no file and leaves the dialog available for another attempt.

The request is `export_page_image({id, revision, page, dpi, format})`. `format` is lowercase `png` or `jpeg`; omitting it remains compatible with PNG, while the interface sends its explicit selected format. It captures the active document ID and revision with the current zero-based physical page; page labels remain display-only and never select the exported page. Native code revalidates the exact revision after the picker before rendering. A successful receipt must repeat the same document ID, revision, physical page, DPI, derived pixel dimensions, and format before the UI reports success.

Pixels are calculated from the current displayed page bounds: `ceil(points × dpi / 72)` for each edge. The UI shows the result before saving. Native code applies the same bounded DPI choices and checks a 16,384-pixel edge limit, 32,000,000 pixels, a 128 MiB copied BGRA bitmap-buffer limit, and a 256 MiB encoded-output limit for either format. The 128 MiB guard bounds the copied BGRA bitmap buffer; it is not a bound on all temporary allocations or total application RSS. PNG contains a `pHYs` density value derived by rounding the selected DPI to pixels per meter, so it represents the selected DPI approximately. JPEG records the selected 72, 150, or 300 DPI density exactly in JFIF metadata; its picker suggests `.jpg`, accepts `.jpg` or `.jpeg`, and rejects format/extension mismatches.

The result is a visible, flattened image of the current page: current crop and rotation, supported sticky notes and highlights, and supported form appearances are included. Both formats are white-flattened 8-bit RGB raster content with no editable PDF text, OCR, vector content, or extra pages. JPEG is lossy at fixed quality 90; its quality cannot be changed. It does not create a PDF tab, recent-file entry, undo item, or source mutation.

Encrypted, restricted, signed, or certified PDFs are refused. The native path also refuses malformed input, stale or closed sessions, parser page-count or page-tree disagreement, unsupported structure, dimensions or output beyond the limits, and invalid or conflicting save destinations. A failed or rejected request keeps the source session unchanged; the dialog reports the error and permits retry.
