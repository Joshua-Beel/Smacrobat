# Export page as PNG

The source build can export one current edited PDF page as a PNG. Open a PDF, choose **Export page as PNG** from Menu or All tools, select 72, 150, or 300 DPI, then choose a new PNG location in Windows. The initial choice is 150 DPI. Canceling the save picker creates no file and leaves the dialog available for another attempt.

The request is fixed to `export_page_image({id, revision, page, dpi})`. It captures the active document ID and revision with the current zero-based physical page; page labels remain display-only and never select the exported page. Native code revalidates the exact revision after the picker before rendering. A successful receipt must repeat the same document ID, revision, physical page, DPI, and derived pixel dimensions before the UI reports success.

Pixels are calculated from the current displayed page bounds: `ceil(points × dpi / 72)` for each edge. The UI shows the result before saving. Native code applies the same bounded DPI choices and checks a 16,384-pixel edge limit, 32,000,000 pixels, a 128 MiB copied BGRA bitmap-buffer limit, and a 256 MiB encoded-PNG limit. The 128 MiB guard bounds the copied BGRA bitmap buffer; it is not a bound on all temporary allocations or total application RSS. The PNG contains a `pHYs` density value derived by rounding the selected DPI to pixels per meter, so it represents the selected DPI approximately.

The result is a visible, flattened image of the current page: current crop and rotation, supported sticky notes and highlights, and supported form appearances are included. It is white-flattened 8-bit RGB raster content with no editable PDF text, OCR, vector content, or extra pages. It does not create a PDF tab, recent-file entry, undo item, or source mutation.

Encrypted, restricted, signed, or certified PDFs are refused. The native path also refuses malformed input, stale or closed sessions, parser page-count or page-tree disagreement, unsupported structure, dimensions or output beyond the limits, and invalid or conflicting save destinations. A failed or rejected request keeps the source session unchanged; the dialog reports the error and permits retry.
